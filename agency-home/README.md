# Silverback AI — agency homepage (static)

Static homepage for https://silverbackai.agency/ — plain HTML + CSS, no framework, no build tool.

```
agency-home/
  index.html            homepage (sections: #solutions #industries #approach #about #contact)
  credits.html          photo credits (CC licenses)
  assets/css/site.css   styles (cream / black / gold, system font stack)
  assets/img/           generated by scripts/fetch_images.py (not committed)
  favicon.svg           gorilla mark
  robots.txt, sitemap.xml, _headers
  scripts/fetch_images.py  downloads the licensed photos and builds optimized WebP/JPG
```

## Build images
```
pip install pillow
python3 agency-home/scripts/fetch_images.py
rsvg-convert -w 180 -h 180 agency-home/favicon.svg > agency-home/apple-touch-icon.png   # optional
```

## Deploy (Cloudflare Pages project `silverback-site`)
```
npx wrangler pages deploy agency-home --project-name=silverback-site --branch=main
```
Or run the manual GitHub workflow "Deploy agency homepage" (needs repo secrets
CLOUDFLARE_API_TOKEN with Pages:Edit, and CLOUDFLARE_ACCOUNT_ID).

## Extending
Each solution card links to a mailto stub (`#counsel`, `#blue-collar`, `#compliant`);
replace the link with a deeper page (e.g. /counsel/) when it exists.
